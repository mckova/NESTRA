# Limits and interpretation

- **A subset, not the product.** This artifact contains three upstream modules plus a new showcase wrapper. It does not demonstrate the full NESTRA runtime, gateway, routing cascade or learned router.
- **No generated answer.** Source excerpts are retrieved text, not output from a real or fake LLM. Zero provider calls describe the implemented execution path, not a measured token-cost improvement.
- **Lexical matching.** English fixtures exercise simple word overlap. They do not establish paraphrase handling, morphology coverage or semantic entailment. A source match is not proof that a question can be answered completely.
- **Language scope.** Authored documentation, demo, fixtures, CLI help/output and tests are in English. Multilingual regular-expression patterns in the inherited core are algorithm data retained verbatim; their presence is not a multilingual evaluation.
- **Demo policy.** Relevance and disclosure decisions are explicit wrapper rules. They are not a replacement for a production authorization service.
- **Author-assigned metadata.** Fixture trust and sensitivity are controlled labels. The program does not establish source authenticity or discover real-world document permissions.
- **Heuristic injection checks.** Pattern matching can miss attacks and flag harmless text. No comprehensive prompt-injection resistance is claimed.
- **Synthetic data only.** The examples are invented. They do not measure quality on real organizational knowledge, schools, customers or confidential documents.
- **No model benchmark.** Passing the showcase checks establishes the tested behavior and invariants only. It does not establish LLM answer quality, accuracy preservation, multilingual model quality or production security.
- **No installation or deployment exercise.** Running from a directory with an existing Python interpreter is the supported path. This directory provides no public service or package release.
- **Attribution retained.** The copied files keep their original MIT license and copyright notice. Public release still requires review of rights and the exact release files; Git history was unavailable during source review.
- **Source verification is separate.** The private sibling review directory holds source metadata and integrity evidence. It is not part of the showcase and should not be included in a public package.

For any release or correction, review the exact selected files, confirm attribution and ownership, rerun the documented checks on those files, and inspect the captured example output. Release operations follow the user's authorized workflow. This documentation correction does not itself perform publication or network operations.
