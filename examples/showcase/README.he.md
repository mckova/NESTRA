# תצוגת NESTRA מקומית ללא מודל שפה

[English](README.md)

הדגמה קטנה ודטרמיניסטית בעברית של **שליפת מקורות וקבלת החלטות מדיניות**, על נהלי צוות מומצאים בלבד. היא משתמשת בחלק שנבדק מקוד הזיכרון והשליפה המילולית של NESTRA. אין בדמו יצירת תשובה באמצעות LLM.

הדמו מציג שאלה עם מקורות תומכים, שאלה שאין עבורה די ראיות, ומקור רלוונטי שהמדיניות אינה מאפשרת להציג. קטעי מקור מוצגים רק כאשר מדיניות התצוגה מתירה זאת.

## הרצה

נדרש Python קיים בגרסה 3.10 ומעלה. אין צורך בהתקנת חבילות, הורדת מודלים, חשבון או מפתחות. מתוך התיקייה הזאת:

```powershell
python -I -B demo.py
python -I -B demo.py --json
python -I -B demo.py --case supported
python -I -B demo.py --help
```

התצוגה הרגילה בעברית; JSON מאפשר לעיין בהחלטות ולבדוק אותן. האפשרות `--case` בוחרת `supported`, ‏`insufficient`, ‏`untrusted` או `restricted`. שני מצבי הפלט משתמשים באותן החלטות של היישום.

קובץ ההפעלה מוסיף לנתיב הייבוא רק את `src` של התצוגה. הדגל `-I` מבודד את Python מהגדרות משתמש ומ־`PYTHONPATH`, והדגל `-B` מונע יצירת קובצי bytecode. הדמו אינו קורא מסמכים חיצוניים או מפתחות מהסביבה, אינו שומר זיכרון בדיסק ואינו פותח שרת. הפניות המקור בדוגמאות הן תוויות ולא כתובות שהדמו פונה אליהן.

## מה רואים

| שכבה | תפקיד |
|---|---|
| שליפה | קוד NESTRA המועתק בונה אינדקס בזיכרון של מסמכים סינתטיים ומציע ראיות בהתאמה מילולית. |
| מדיניות התצוגה | קוד מעטפת חדש מחיל את כללי הרלוונטיות, האמון והרגישות של הדמו וקובע אם להציג קטעי מקור. |
| ספק מודל | לא מוגדר. אין LLM אמיתי או מדומה; מספר הקריאות לספק הוא אפס. |

ארבעת המקרים מדגימים, בהתאמה, ראיה מותרת, ראיות שאינן מספיקות, מקור לא מהימן ומקור שרגישותו מגבילה הצגה. JSON כולל קודי סיבה למדיניות; `generated_answer` תמיד `null`.

המצב `sources_found` אומר שנמצאה ראיית מקור המותרת להצגה. הוא אינו אומר שתשובה שנוצרה נכונה, או שהמקור מוכיח סמנטית כל חלק בשאלה. במצבי `no_evidence` ו־`blocked` לא מוחזרים קטעי מקור.

לסקירה מהירה: [פלט טקסט](examples/demo-output.txt), [פלט JSON](examples/demo-output.json), [ארכיטקטורה](docs/ARCHITECTURE.md), [מגבלות](docs/LIMITATIONS.md).

## בדיקות

```powershell
python -I -B run_checks.py
```

הבדיקות משתמשות בספרייה הסטנדרטית של Python. הן בודקות את החלק שהופרד ואת התנהגות הדמו החדש, ולא את מוצר NESTRA המלא. תוצאת ההרצה בפועל מופיעה ב[דוח האימות](docs/VALIDATION.md); עצם קיומו של קובץ בדיקה אינו תוצאת מעבר.

## גבולות וייחוס

- `src/nestra_core/project_memory.py`, ‏`memory.py` ו־`security.py` הועתקו ללא שינוי מצילום מצב מקומי של NESTRA.
- `PROVENANCE.json` מכיל רשימת קבצים מפורשת וחתימות SHA-256 של הקבצים שהועתקו, כולל הרישיון שנשמר.
- המעטפת ב־`src/nestra_showcase`, קובצי ההפעלה, הדוגמאות, הבדיקות והתיעוד נכתבו עבור התצוגה המבודדת.
- לא הועתקו ה־runtime המלא, שרת HTTP, מחברי ספקי מודלים, מודל ניתוב נלמד, benchmarks או זיכרון משתמשים.

תיקיית המקור אינה תלות להרצת התצוגה. ראיות הסקירה הפרטיות שמחוץ לתצוגה כוללות חתימות של רשימת הקבצים שהועתקו והשוואת מטא־דאטה של עץ המקור לפני העבודה ואחריה. זו אינה בדיקת חתימות תוכן לכל קובץ במקור. היסטוריית Git לא נבדקה.

כל השמות, הנהלים והתוכן בדמו מומצאים. אמון ורגישות מוגדרים במטא־דאטה של הדוגמאות בידי מחבר הדמו; המערכת אינה מאמתת כך עובדות או הרשאות של ארגון אמיתי.
