# Pre-separation artifacts

These JSON files are immutable evidence from experiments run while NESTRA research was accidentally located inside the Agent Hive repository. Names containing `Hive` reflect that historical mistake.

Mapping used by the separated project:

- `agentHive` → the old fixed four-role baseline; current name `fixedNestra`
- `adaptiveMemoryHive` → `adaptiveMemoryNestra`
- `accuracyLockedMicroHive` → `accuracyLockedMicroNestra`
- `microHive100` → `microNestra100`

The artifacts were not rewritten because preserving exact generated evidence is more important than cosmetic renaming.
